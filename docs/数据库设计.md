# 数据库设计

## 2.1 数据库环境

- 数据库管理系统：MySQL 5.7
- 字符集：utf8mb4
- 数据库名：dasi_kjbc_keshe

本模块在原有数据库基础上新增 **category（商品分类）表**，并在 **product（商品）表** 中新增 `category_id` 字段用于关联分类表，其余字段保持不变。

---

## 2.2 商品分类表 category

### 2.2.1 表结构

| 字段名      | 数据类型      | 约束                              | 说明         |
|-------------|---------------|-----------------------------------|--------------|
| id          | bigint        | PRIMARY KEY, AUTO_INCREMENT       | 分类ID       |
| name        | varchar(50)   | NOT NULL, UNIQUE                  | 分类名称     |
| sort        | int           | DEFAULT 0                         | 排序（升序） |
| create_time | datetime      | DEFAULT CURRENT_TIMESTAMP         | 创建时间     |

### 2.2.2 建表语句

```sql
CREATE TABLE IF NOT EXISTS category (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '分类ID',
    name VARCHAR(50) NOT NULL UNIQUE COMMENT '分类名称',
    sort INT DEFAULT 0 COMMENT '排序（升序）',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='商品分类表';
```

### 2.2.3 初始数据

```sql
INSERT INTO category (name, sort) VALUES
    ('生活用品', 1),
    ('教材', 2),
    ('数码', 3),
    ('运动', 4),
    ('出行', 5),
    ('服饰', 6);
```

## 2.3 商品表 product（修改）

### 2.3.1 新增字段

| 字段名       | 数据类型 | 约束                | 说明                         |
|--------------|----------|---------------------|------------------------------|
| category_id  | bigint   | NULL, INDEX         | 分类ID（外键关联category.id）|

> 原 `category` 字段（varchar(50)）保留，作为冗余字段存储分类名称，与分类表 `name` 保持一致，用于减少列表查询时的关联操作。

### 2.3.2 修改语句

```sql
ALTER TABLE product ADD COLUMN category_id BIGINT NULL COMMENT '分类ID' AFTER category;
ALTER TABLE product ADD INDEX idx_category_id (category_id);
```

### 2.3.3 回填数据

```sql
UPDATE product SET category_id = (SELECT id FROM category WHERE category.name = product.category)
WHERE category IS NOT NULL;
```

## 2.4 ER 关系说明

```
category (1) ────────< (N) product
  id (PK)                  id (PK)
  name                     category_id (FK → category.id)
  sort                     category (冗余，= category.name)
  create_time              ... (其余字段不变)
```

- 一个分类下可以有多个商品，一个商品只属于一个分类（一对多）。
- `product.category_id` 为外键，关联 `category.id`。
- `product.category` 为冗余字段，写入商品时由后端根据 `category_id` 自动查询分类名称并填充，保证数据一致性。

## 2.5 文件上传存储设计

上传文件保存在服务器本地磁盘，不存入数据库。

- 存储根目录：`${项目根目录}/uploads/`
- 目录结构：`uploads/yyyyMMdd/UUID.扩展名`
- 访问 URL 前缀：`/uploads/**`，由 Spring MVC 静态资源映射提供 HTTP 访问。
- 数据库 `product.image_url` 字段保存上传后的访问 URL。
