# 系统概要设计

## 3.1 模块概述

本模块属于校园二手交易系统中的 **商品分类与分布子模块**，在已有商品浏览、发布、收藏、留言等功能基础上，扩展以下四项功能：

1. **商品分类管理**：新增商品分类表，支持分类的增删改查，商品通过 `category_id` 关联分类。
2. **商品分布统计**：按分类和价格区间统计在售商品数量，以柱状图可视化展示。
3. **商品编辑**：管理员可编辑商品信息（标题、描述、分类、价格、图片、上下架状态等）。
4. **特色文件上传**：提供统一的图片上传接口，支持商品图片的本地上传与访问。

## 3.3 功能模块划分

| 功能模块     | 后端类/接口                                   | 前端组件                      |
|--------------|-----------------------------------------------|-------------------------------|
| 分类管理     | CategoryController / CategoryService / CategoryMapper | api/category.js               |
| 商品分布     | ProductDistributionController.distribution / ProductStatsMapper 统计方法 | ProductDistribution.vue       |
| 商品编辑     | ProductController.update / ProductService.updateProduct | ProductEdit.vue               |
| 文件上传     | FileController.upload / WebMvcConfig 资源映射  | ProductEdit.vue 上传组件      |

## 3.4 接口设计概要

### 3.4.1 分类接口

| 方法 | 路径          | 说明       | 鉴权 |
|------|---------------|------------|------|
| GET  | /categories   | 分类列表   | 否   |
| GET  | /categories/{id} | 分类详情 | 否   |
| POST | /categories   | 新增分类   | 是   |
| PUT  | /categories/{id} | 修改分类 | 是   |
| DELETE | /categories/{id} | 删除分类 | 是 |

### 3.4.2 商品接口（扩展）

| 方法 | 路径                     | 说明         | 鉴权         |
|------|--------------------------|--------------|--------------|
| GET  | /products/distribution   | 商品分布统计 | 否           |
| POST | /products                | 发布商品     | 是（管理员） |
| PUT  | /products/{id}           | 编辑商品     | 是（管理员） |

### 3.4.3 文件上传接口

| 方法 | 路径     | 说明       | 鉴权 |
|------|----------|------------|------|
| POST | /upload  | 图片上传   | 是   |

## 3.5 设计原则

1. **最小侵入**：尽量不修改现有代码，新增表与字段，新增 Controller/Service/Mapper。
2. **冗余设计**：`product.category` 保留为冗余字段，避免列表查询频繁关联分类表。
3. **权限控制**：发布与编辑商品仅管理员可操作，上传接口需登录。
4. **统一响应**：所有接口返回 `Result<T>` 统一结构（code/message/data）。
