## 4.2 商品分布统计

### 4.2.1 需求

统计在售商品（status=1）在不同分类和价格区间的分布数量，返回给前端用于柱状图展示。

### 4.2.2 Mapper 统计 SQL

位置：`mapper/ProductMapper.java`

**按分类统计：**

```java
@Select("SELECT category_id AS categoryId, category AS categoryName, COUNT(*) AS `count` " +
        "FROM product WHERE status = 1 AND category_id IS NOT NULL " +
        "GROUP BY category_id, category ORDER BY `count` DESC")
List<Map<String, Object>> selectCategoryStats();
```

**按价格区间统计：**

```java
@Select("SELECT " +
        "CASE " +
        "WHEN price < 50 THEN '0-50元' " +
        "WHEN price < 100 THEN '50-100元' " +
        "WHEN price < 200 THEN '100-200元' " +
        "ELSE '200元以上' END AS `range`, " +
        "COUNT(*) AS `count` " +
        "FROM product WHERE status = 1 " +
        "GROUP BY `range` ORDER BY MIN(price)")
List<Map<String, Object>> selectPriceStats();
```

> 注意：`range`、`count` 为 MySQL 保留字，SQL 中需用反引号转义。

### 4.2.3 Service 处理

位置：`service/impl/ProductServiceImpl.java`

```java
public Map<String, Object> getDistribution() {
    List<Map<String, Object>> categoryStats = productMapper.selectCategoryStats();
    List<Map<String, Object>> priceStats = productMapper.selectPriceStats();
    int total = categoryStats.stream()
            .mapToInt(m -> ((Number) m.get("count")).intValue()).sum();
    Map<String, Object> result = new HashMap<>();
    result.put("categoryStats", categoryStats);
    result.put("priceStats", priceStats);
    result.put("total", total);
    return result;
}
```

### 4.2.4 Controller 接口

```java
@GetMapping("/distribution")
public Result<Map<String, Object>> distribution() {
    return Result.success(productService.getDistribution());
}
```

### 4.2.5 返回数据结构

```json
{
  "code": 200,
  "data": {
    "categoryStats": [
      {"categoryId": 1, "categoryName": "生活用品", "count": 2},

    ],
    "priceStats": [
```

- 调用 `getProductDistribution()` 获取数据。

## 4.3 商品编辑

### 4.3.1 需求

商品发布者可编辑自己发布的商品，修改标题、描述、分类、价格、图片等信息。非发布者无权编辑。

### 4.3.2 实体扩展

位置：`entity/Product.java`

```java
private Long categoryId;  // 新增字段，关联分类表
```

### 4.3.3 Service 编辑逻辑

位置：`service/impl/ProductServiceImpl.java`

```java
public Product update(Long id, Long userId, ProductUpdateDTO dto) {
    Product product = productMapper.selectById(id);
    if (product == null) throw new RuntimeException("商品不存在");
    if (!product.getUserId().equals(userId)) throw new RuntimeException("无权修改他人商品");

    product.setTitle(dto.getTitle());
    product.setDescription(dto.getDescription());
    product.setCategoryId(dto.getCategoryId());
    product.setPrice(dto.getPrice());
    product.setImageUrl(dto.getImageUrl());
    product.setStatus(dto.getStatus());
    product.setUpdateTime(LocalDateTime.now());

    // 根据 categoryId 回填冗余字段 category（分类名称）
    if (dto.getCategoryId() != null) {
        Category category = categoryMapper.selectById(dto.getCategoryId());
        product.setCategory(category != null ? category.getName() : null);
    }
    productMapper.updateById(product);
    return product;
}
```

**设计要点：**
- 权限校验：`product.userId` 必须等于当前登录用户 ID。
- 冗余字段同步：根据 `categoryId` 查询分类名称，写入 `category` 字段，保证一致性。
- 自动更新 `update_time`。

### 4.3.4 Controller 接口

```java
@PutMapping("/{id}")
public Result<Product> update(@PathVariable Long id,
                              @RequestBody ProductUpdateDTO dto,
                              @RequestAttribute("userId") Long userId) {
    return Result.success(productService.update(id, userId, dto));
}
```

### 4.3.5 JwtInterceptor 放行策略

修改 `config/JwtInterceptor`，对商品相关 GET 请求放行（列表、详情、分布），对 PUT（编辑）请求拦截并校验 token，从 token 中解析 `userId` 注入 `request`。

### 4.3.6 前端编辑页面

位置：`views/ProductEdit.vue`

## 4.4 特色文件上传

### 4.4.1 需求

提供统一的图片上传接口，支持 jpg/png/gif/webp 格式，文件保存到服务器本地，返回可访问的 URL。

### 4.4.2 配置

位置：`application.yml`

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 5MB
      max-request-size: 10MB

app:
  upload:
    path: ./uploads
    url-prefix: /uploads
```

### 4.4.3 FileController

位置：`controller/FileController.java`

```java
@RestController
@RequestMapping("/upload")
public class FileController {

    private static final Set<String> ALLOWED_TYPES = new HashSet<>(Arrays.asList(
            "image/jpeg", "image/png", "image/gif", "image/webp", "image/jpg"));

    @Value("${app.upload.path}") private String uploadPath;
    @Value("${app.upload.url-prefix}") private String urlPrefix;

    @PostMapping
    public Result<String> upload(@RequestParam("file") MultipartFile file) throws IOException {
        // 1. 非空校验
        // 2. 文件类型白名单校验
        // 3. 生成文件名：yyyyMMdd/UUID.扩展名
        // 4. 路径解析：相对路径基于 user.dir 转为绝对路径
        Path baseDir = Paths.get(uploadPath).isAbsolute()
                ? Paths.get(uploadPath)
                : Paths.get(System.getProperty("user.dir"), uploadPath);
        File destDir = baseDir.resolve(dateDir).toFile();
        if (!destDir.exists()) destDir.mkdirs();
        file.transferTo(baseDir.resolve(relativePath).toFile());
        // 5. 返回访问 URL
        return Result.success(urlPrefix + "/" + relativePath);
    }
}
```

**关键设计：**
- **类型白名单**：只允许图片格式，防止上传恶意文件。
- **UUID 文件名**：避免文件名冲突和中文乱码问题。
- **按日期分目录**：`uploads/yyyyMMdd/` 便于管理。
- **绝对路径解析**：`user.dir`（项目根目录）为基准，避免相对路径被解析到 Tomcat 临时目录。

### 4.4.4 静态资源映射

位置：`config/WebMvcConfig.java`

```java
@Override
public void addResourceHandlers(ResourceHandlerRegistry registry) {
    Path baseDir = Paths.get(uploadPath).isAbsolute()
            ? Paths.get(uploadPath)
            : Paths.get(System.getProperty("user.dir"), uploadPath);
    registry.addResourceHandler(urlPrefix + "/**")
            .addResourceLocations("file:" + baseDir.toAbsolutePath() + "/");
}
```

将 `/uploads/**` 请求映射到本地 `uploads/` 目录，实现上传文件的 HTTP 访问。

### 4.4.5 鉴权

`/upload` 路径加入 JwtInterceptor 拦截列表，需登录后才能上传。
